# UUID Generator 项目需求文档

## 目标与边界

帮助第一次做出海网站的使用者完成一个可用、可上线的小工具。关键词为 UUID generator。用户已确认：单页、包含工具与说明和常见问题；手机及电脑可用；不需要账号；离开或刷新后不保留历史。已有 GitHub、Vercel、Google 账号，没有域名，域名预算每年人民币 100 元以内。

语言和生成数量未收到明确选项，本版采用此前推荐的默认值：英文界面，一次一个 UUID。生成标准选 UUID v4，输出小写、含连字符的 36 个字符。暂不加入批量生成、下载、版本切换、文章、广告、付费、访问统计、数据库或后台管理。

## 使用流程

打开首页 → 自动获得一个 UUID → 点击 Copy UUID 复制 → 点击 Generate new 替换为新的 UUID。编号仅在当前页面内存中；刷新重新生成，从浏览器返回缓存恢复页面也重新生成。用户主动复制到剪贴板的内容不由网站清除。

复制成功显示 Copied!；如果浏览器阻止复制，自动选中编号并提示使用设备的复制命令。浏览器无法提供可靠随机来源时显示错误，不生成低质量替代编号。关闭 JavaScript 时显示开启提示。

## 页面与可访问性

导航、工具区、三步使用说明、六项常见问题、页脚。手机自动变成单列；编号必要时换行但不改变实际内容。按钮可通过键盘操作，焦点可见，操作结果通过状态区域提示。使用系统字体，无远程字体及图片依赖。

## 技术方案

HTML 负责页面内容，CSS 负责外观，JavaScript 负责生成与复制。Node.js 仅用于本地启动和部署前整理文件，线上为静态文件。使用浏览器的 `crypto.randomUUID()`；不支持时使用 `crypto.getRandomValues()` 并设置 v4 所需位，不使用 Math.random。浏览器生成方式参考 [MDN 文档](https://developer.mozilla.org/en-US/docs/Web/API/Crypto/randomUUID)。

站点代码不存储和上传 UUID。托管服务仍可能产生普通请求日志，因此不承诺网站绝对没有访问记录。

## 搜索准备

首页有英文标题、描述、唯一一级标题和可直接读取的说明文字。正式域名通过 SITE_URL 指定，构建时生成首页规范地址、robots.txt 和 sitemap.xml。站点地图只包含首页，不包含错误页或页面内锚点。预览部署不开放索引；正式部署有有效网址才开放索引。Search Console 使用域名记录验证，无需在页面嵌入验证码。

## 功能验收

- 初次打开显示符合 8-4-4-4-12 格式的 UUID，第三段首字符为 4，第四段首字符为 8、9、a 或 b。
- 复制到记事本后与页面内容一致；重新生成后内容更新。
- 刷新后产生新编号，无历史列表或登录入口。
- 手机窄屏可读，按钮不遮挡，页面无横向滚动。
- 复制失败时有可执行提示；禁用脚本时有提示。
- 自动测试覆盖 10,000 次格式及样本内重复检查、备用生成路径、随机来源缺失情况。样本测试不能证明所有 UUID 永不重复。
