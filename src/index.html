A little context

Good questions.

What is a UUID?

UUID stands for universally unique identifier. It is a 128-bit value, usually written as 32 hexadecimal characters separated by four hyphens: 36 characters in total.

Which UUID version does this generate?

This tool generates random version 4 UUIDs using your browser’s cryptographically secure random generator. The output uses lowercase letters and the standard 8-4-4-4-12 format.

Can two UUIDs be the same?

Duplicates are possible, but extremely unlikely with correctly generated UUID v4 values. They contain 122 random bits. For important records, your application should still enforce uniqueness.

Are my UUIDs saved or sent anywhere?

This tool generates UUIDs on your device. It does not store them or send them to a server. Copying writes only the current UUID to your clipboard. The hosting provider may process normal page request logs.

Is this free to use?

Yes. Generate and copy UUIDs without an account. This first version creates one UUID at a time.

Can I use a UUID as a password?

A UUID is intended to identify something. Use a dedicated password or secret generator for credentials.
